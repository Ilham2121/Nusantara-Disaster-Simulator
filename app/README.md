# 🌋 Nusantara Disaster Simulator - Frontend & 3D Web App

Direktori ini berisi kode sumber utama aplikasi web **Nusantara Disaster Simulator**, dibangun menggunakan Next.js App Router, React Three Fiber (Three.js), TailwindCSS, dan Zustand.

Untuk dokumentasi lengkap proyek, prosedur push GitHub, dan panduan kontribusi, silakan baca [README Utama](../README.md) dan [Panduan Kontributor](../CONTRIBUTING.md).

## 🚀 Perintah Cepat

```bash
# Menjalankan dengan Docker (dari root folder)
docker compose -f docker-compose.dev.yml up --build

# Atau secara lokal dengan npm:
# Install dependensi
npm install

# Jalankan server development
npm run dev

# Jalankan unit tests (Vitest)
npm run test

# Jalankan E2E tests (Playwright)
npm run test:e2e

# Build produksi
npm run build
```
